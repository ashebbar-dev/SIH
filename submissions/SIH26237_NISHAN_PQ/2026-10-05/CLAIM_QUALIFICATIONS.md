# Qualifications for the accompanying PDF

These notes are part of the evidence release and take precedence over shorthand
claims in the unchanged, user-prepared PDF. They do not change the measured results.

| Slide wording | Evidence-supported reading |
| --- | --- |
| "Everything" or "every number regenerates offline with the repo's commands" | Stable digital benchmarks have source and reproduction commands. Research source and selected evidence are published separately. Physical inputs, private runtime state and some local working artifacts are excluded. External industry statistics are cited facts, not outputs of this repository. |
| "TESTED TODAY" | The slide's runs were performed on **28 September 2026**, not on the publication date. Any October smoke/core check is identified separately. |
| "0 false accusations in 175 attacks" | No non-source row crossed the accusation threshold in **25 carrier cases, 120 code-level cases, and 30 JPEG release trials**, considered as three different study strata. This is not 175 independent physical or complete attribution trials and not a calibrated zero error probability. |
| PDF/screenshot/JPEG all follow a two-channel attribution flow | A supported clean PDF with agreeing visual/layout evidence can identify a signed release. Raster-only screenshot/JPEG results are **investigative leads**, not verified two-channel session attribution. |
| "Can't be framed", "never a wrong name", "guilty" | Tested pasted/stripped/conflicting-mark cases cause abstention. The operator can reproduce a known recipient mark. A matched source copy or release does not establish which human disclosed it. |
| "Immutable provenance", "no admin can quietly rewrite history", all requirements implemented | The prototype keeps four logical replicas, synthetic identity keys and the witness on one machine. Rollback detection assumes retained trusted witness state/key. This does not demonstrate resistance to a single operator controlling both quorum and witness. Independent administration is a deployment requirement still to demonstrate. |
| All tampering blocks release | A single-replica edit can be detected while an intact quorum remains valid. Rollback, wrong pin and injected checkpoint failures have separate fail-closed tests. |
| "8/8 attacks caught" | Eight named security conditions were detected or blocked; these are not eight independent real-world attacker studies. |
| Tardos guarantees cover photos or the signed-compact pilot | Code-level bounds require their formal assumptions. They do not automatically cover physical channels, compact tokens, arbitrary coalitions, or issuer framing. |
| Print/photo roadmap accompanied by 13 + 63 tests | Those tests are for an isolated experimental **digital signed-compact adapter**. They are not successful print/photo trials. |

The JPEG study uses a fixed source/codebook and a single named recipient with
multiple sessions. It is not a twenty-person, multi-document deployment study.
Retained evidence should be read at the per-trial level; the scorer and attribution
policy are distinct stages.

The best completed physical development comparison reports 9/24 finite associations,
2/24 exact reconstructions, and 0/6 marked tilted successes. Research tuning on
this corpus means it must not be called an untouched production validation set.
Later source/clean-render checks must not be promoted to new physical results.

The full original 291-commit local history count describes work performed across
research branches, not 291 validated product improvements. Publication does not
turn failed or incomplete work into successful capabilities.
